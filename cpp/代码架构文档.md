## 项目概述

### 设计目标
提供一个高性能、易于扩展的军棋暗棋环境，用于强化学习研究和游戏开发。

### 技术栈
- **语言**: C++17
- **Python绑定**: PyBind11
- **构建系统**: CMake
- **设计模式**: 
  - 单一职责原则
  - 依赖注入
  - 策略模式

### 核心特性
- ✅ 完整的军棋规则实现
- ✅ 高效的合法动作生成（BFS搜索）
- ✅ 自动布阵生成与验证
- ✅ 全知/局部观测模式
- ✅ PyBind11 Python接口
- ✅ 类型安全的C++实现

```cpp
public:
```

```cpp
    // 验证双方布阵
    bool validate_both_setups(const std::vector<int>& red_setup,
                           const std::vector<int>& black_setup,

private:
    // 检查棋子数量
    bool check_piece_count(const std::vector<int>& setup,

    // 检查位置限制
    bool check_position_restrictions(const std::vector<int>& setup,
                                   PlayerId player,
                                   std::string& error_message) const;
    
    // 具体验证
    bool check_flag_position(const std::vector<int>& setup,
                            PlayerId player,
                            std::string& error_message) const;
    bool check_mine_position(const std::vector<int>& setup,
                            PlayerId player,
                            std::string& error_message) const;
    bool check_bomb_position(const std::vector<int>& setup,
                            PlayerId player,
                            std::string& error_message) const;
    bool check_camp_empty(const std::vector<int>& setup,
                          PlayerId player,
                          std::string& error_message) const;
    
    // 辅助函数
    std::map<PieceType, int> get_piece_count_map(
        const std::vector<int>& setup) const;
    int get_start_row(PlayerId player) const;
    
    const JunqiBoard& board_;
};
```

**验证规则**:
1. **数量检查**: 每方25个棋子（地雷3、炸弹2、军旗1等）
2. **军旗位置**: 必须在大本营（红方位置1或3，黑方位置31或33）
3. **地雷位置**: 只能在最后两排（红方行0-1，黑方行10-11）
4. **炸弹位置**: 不能在前线（红方行5，黑方行6）
5. **行营检查**: 5个行营必须为空
6. **布阵大小**: 必须为30个位置

**使用示例**:
```cpp
JunqiBoard board;
SetupValidator validator(board);

// 验证红方布阵
std::vector<int> red_setup = {/* ... */};
std::string error;
if (validator.validate_setup(red_setup, RED, error)) {
    printf("红方布阵合法\n");
} else {
    printf("红方布阵非法: %s\n", error.c_str());
}

// 验证双方
std::vector<int> black_setup = {/* ... */};
if (!validator.validate_both_setups(red_setup, black_setup, error)) {
    printf("布阵验证失败: %s\n", error.c_str());
}
```

### 6. move_generator.h / .cpp

**作用**: 生成所有合法移动动作

**核心功能**:
```cpp
class MoveGenerator {
public:
    MoveGenerator(const JunqiBoard& board);
    
    // 生成所有合法动作
    std::vector<std::pair<int, int>> generate_legal_moves(
        const JunqiState& state) const;
    
    // 生成动作掩码（3600维）
    std::vector<bool> get_legal_action_mask(
        const JunqiState& state,
        PlayerId player) const;
    
    // 检查单个动作
    bool is_move_valid(const JunqiState& state,
                      int from,
                      int to) const;
    
private:
    // 生成单个棋子的移动
    std::vector<int> generate_piece_moves(
        const JunqiState& state,
        int from) const;
    
    // 公路移动
    std::vector<int> generate_highway_moves(
        const JunqiState& state,
        int from) const;
    
    // 铁路移动（普通棋子）
    std::vector<int> generate_railway_moves(
        const JunqiState& state,
        int from) const;
    
    // 工兵铁路移动（可拐弯）
    std::vector<int> generate_sapper_railway_moves(
        const JunqiState& state,
        int from) const;
    
    // BFS搜索铁路路径
    std::vector<int> bfs_railway_search(
        const JunqiState& state,
        int start) const;
    
    // 路径检查
    bool is_railway_path_clear(const JunqiState& state,
                               int from,
                               int to) const;
    bool is_railway_line_clear(const JunqiState& state,
                               int from,
                               int to) const;
    bool can_enter(const JunqiState& state,
                   int from,
                   int to,
                   PlayerId player) const;
    
    std::vector<int> get_positions_between(int from, int to) const;
    
    const JunqiBoard& board_;
};
```

**移动规则**:
1. **公路**: 只能走相邻格子
2. **铁路**:
   - 普通棋子: 只能走直线（同行或同列）
   - 工兵: 可以拐弯（BFS搜索）
   - 不能穿过棋子
3. **行营**: 任何棋子都能进入
4. **大本营**: 只能进不能出
5. **山界**: 不能通行
6. **不能吃己方棋子**

**算法**:
```cpp
// 普通铁路移动（直线）
for each direction (上下左右):
    while 在铁路上:
        if 遇到棋子:
            if 是敌方:
                可以吃
            break
        else:
            可以移动到这个位置

// 工兵铁路移动（BFS）
queue = [start_pos]
visited = {start_pos}
while queue not empty:
    current = queue.pop()
    for each neighbor:
        if 在铁路上 and not visited and 无棋子阻挡:
            visited.add(neighbor)
            queue.add(neighbor)
            可以移动到这个位置
```

**使用示例**:
```cpp
JunqiBoard board;
JunqiState state;
MoveGenerator move_gen(board);

// 生成所有合法动作
std::vector<std::pair<int, int>> moves = 
    move_gen.generate_legal_moves(state);

// 生成动作掩码
std::vector<bool> mask = 
    move_gen.get_legal_action_mask(state, RED);

// 检查单个动作
bool valid = move_gen.is_move_valid(state, 0, 5);
if (valid) {
    printf("从0移动到5合法\n");
}
```

**战斗规则**:
```cpp
战斗结果表（攻击方 vs 防御方）:

攻击\防御 | 工兵 | 排长 | 连长 | ... | 司令 | 炸弹 | 地雷 | 军旗
---------|-------|-------|-------|-----|------|------|------|------
工兵     |  DRAW |  LOSS |  LOSS | ... | LOSS | WIN   | WIN  | WIN
排长     |   WIN |  DRAW |  LOSS | ... | LOSS | DRAW  | LOSS | WIN
连长     |   WIN |   WIN |  DRAW | ... | LOSS | DRAW  | LOSS | WIN
...      |   ... |   ... |   ... | ... |  ... |  ... |  ... | ...
司令     |   WIN |   WIN |   WIN | ... | DRAW | DRAW  | LOSS | WIN
炸弹     |   LOSS |  DRAW |  DRAW | ... | DRAW | DRAW  | DRAW | WIN
地雷     |   LOSS |   WIN   |  WIN  | ... |  WIN  | DRAW  | DRAW | LOSS
军旗     |   LOSS |   LOSS |  LOSS | ... | LOSS | LOSS  | DRAW | DRAW

特殊规则:
1. 工兵可以挖地雷（WIN）
2. 炸弹与任何战斗单位同归于尽（DRAW）
3. 军旗不能移动，被任何棋子吃掉则游戏结束
4. 工兵在铁路上可以拐弯
5. 相同等级棋子相遇，同归于尽（DRAW）
```

```cpp
        printf("攻击方胜\n");
        break;
    case CombatResult.LOSS:
        printf("攻击方负\n");
        break;
    case CombatResult.DRAW:
        printf("同归于尽\n");
```

```cpp
    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);
    
    printf("10000 games in %ld ms\n", duration.count());
}
```
